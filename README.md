# 🎰 Blackjackist Slot Tracker (Android)

Автоматический трекер слотов для мобильной игры **Blackjackist** (KamaGames).

## ⚠️ Важно
- Это приложение **только считывает текст с экрана** и ведет статистику.
- Оно **НЕ нажимает кнопки**, **НЕ изменяет игру**, **НЕ использует эксплойты**.
- Работает только с игровой валютой (фишками), не с реальными деньгами.

## 📋 Требования
- Android 7.0+ (API 24+)
- Blackjackist установлен на устройстве
- Android Studio Hedgehog (2023.1.1) или новее (для локальной сборки)
- Или GitHub Actions (для удаленной сборки)

## 🚀 Установка через GitHub Actions
1. Создай репозиторий на GitHub
2. Загрузи все файлы из этого ZIP
3. Перейди во вкладку Actions → Build APK
4. Нажми Run workflow
5. Жди 5-10 минут
6. Скачай APK из Artifacts

## 🚀 Установка через Android Studio
1. Открой проект в Android Studio
2. Sync Gradle
3. Build → Build Bundle(s) / APK(s) → Build APK(s)
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`

## 🔧 Настройка
1. Запусти Slot Tracker
2. Введи начальный баланс и ставку
3. Нажми "Открыть настройки Accessibility"
4. Включи "Slot Tracker" в списке
5. Запусти Blackjackist — сервис автоматически начнет отслеживать баланс

## 🎯 Как это работает
1. Accessibility Service мониторит окно Blackjackist
2. Ищет текстовые элементы с числом баланса
3. Определяет тип спина (loss/win/bonus)
4. Сохраняет статистику и показывает в реальном времени

## 🔒 Безопасность
- Приложение не отправляет данные в интернет
- Все данные хранятся локально
- Не требует root-прав
